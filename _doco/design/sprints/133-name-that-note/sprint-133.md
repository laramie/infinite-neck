## Purpose

Purpose of this sprint is to: 
  - Implement the old name-that-note song series using Arpeggio Plugin
    - arpeggio already has: random, string range, position range, note coloring, and display NamedNote based on SingleNote inputs, which can be hidden.
    - one feature would be to get it to read chart like FillPlugin does. However, the reading of SingleNotes is functional and lets User change them in the current Section for immediate results.  Given a Chart, you can always use FillPlugin to create SingleNotes anyway.
