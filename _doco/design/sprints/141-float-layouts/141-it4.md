# sprint-141-float-layouts Iteration 4

Testing is going well!

We would just like some more features to round out sprint-141.

# Iteration 4 features

1) on click of `.dock-handle`, set the floating div to the highest zIndex of the floating divs.  Treat all currently floating divs as a deck of cards, where the touched card becomes the top, and the rest of the stack retains its relative order.  So if the zIndex values are 200, 210, 220, 230, and we have clicked the div with 210, give 210 the value 230, and move 220 to 210, move 230 to 220.

2) Retain this zIndex in `noteTablesLayout[i].anchorage.zIndex`

3) When new tables are floated (tables that have no zIndex in noteTablesLayout), assign max(zIndex) +10 to the new window, just looking at the floating tables, starting at 200, and not including the Transport, which is hardcoded at 1000.  Really we should only be looking at things in noteTablesLayout for zIndex values to max(), since we will add other tool windows to zIndex calculations separately.

4) Retain the value of `data-handle-orientation` in `noteTablesLayout[i].anchorage.handleOrientation` and use it when Floating a table from docked or from file-load.

5) implement `refloatAllDockables()`, called from `key-handlers.js`.  This function should walk all entries in noteTablesLayout and include any that have non-empty `anchorage.floatRec` values.  (We will make a mechanism later to clear this from tables that should not participate, or create groups of these.)  The purpose of this is to have an opposite to `/vwd` (dock all), that restores the floats the User wants. This function should still work if some of the group have already been re-floated.

# Post-implementation feature

That works perfectly.
Now we would like the special keyboard shortcut `SHIFT`+`ESC` to toggle back and forth between these two states, using the same mechanisms in `/vwd` and `/vwr`

If any tables are floated, then the state is considered floated-all, and the shortcut should dock all.  If none are floated, then the state is floated-none, and the shortcut should re-float all.

We believe that with an early retutrn, the current use of `ESC` can continue to work.  If shift is present, and ESC, we should early return from the key handler after completing the above feature, otherwise continue with current handling of ESC.
