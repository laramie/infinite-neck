# sprint-141-float-layouts

# Problem Statement

Purpose of this sprint is to: 
- Fix bugs in floating windows. 
- Figure out how to have floating windows persist their state.


## Bugs
  - when you do anything in the MyTunings tab, but the Instrument is floated, no changes take effect.  When you dock it, changes, such as "Frets" with the SELECT `.selectFrets` take effect again.
  - when you open a new song with a Tool singleton, it opens a new one docked, but leaves the old one floating.  For example, open songs/tests/Perfect4thsCalculatorTest.json via the File | Choose File button, then float the Perfect4thsCalculator instrument, then open the song again.  The floated window stays around, but if you mash on the float button for the docked instance, it won't move, because another div with the same id is already floated.  When you mash on the UF (UnFreeze) button on either one, it affects both, so the are the same id, again.  Similarly with clicking to place notes.  Docking the extra one solves the problem.

## Floating Window Design

A bigger question is how to correctly make these things persist their floated/docked state.  We want it to be in 
```
"noteTablesLayout": [
    {
      "tableID": "tblP46_1",
      "visible": true
    },
    {
      "tableID": "tblPerfect4thsCalculator_singleton",
      "visible": true
    }
  ],
```

For example: 
```
"noteTablesLayout": [
    {
      "tableID": "tblP46_1",
      "visible": true
    },
    {
      "tableID": "tblPerfect4thsCalculator_singleton",
      "visible": true,
      "floated": true
    }
  ],
```  

Or a multi-state property if needed.

Upon opening a song, if "floated" === true for any NoteTable per "noteTablesLayout" then that instrument/table should be floated after everything has loaded.  If it is floated when the song is saved, it should be marked as such.  If it is docked, then probably it should be stored as "floated": false.

## Remember Layouts for all Floated Windows

We will likely need noteTablesLayout extended with properties so that *any* Instrument NoteTable can be floated with its existing Float button, and the location it ends up being dragged to saved on File Download.  These should be restored on opening a song.

For this first iteration, we don't want coding changes, just an analysis of what we will need to do, change, and design choices we will need to make.
