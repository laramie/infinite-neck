# sprint-111-cleanup-plugins-menus

Purpose of this sprint is to: 
- cleanup the plugins menus, specifically, ordering Actions higher in the order, and moving string, range, and position options to be consistent across plugins
- add a few items to the command-line menu around plugins and the menu structure
- add a few keymapping for global keystrokes in the app to tie into the plugin command-line menus.
- ensure that the developer tools for auditing menus can show current needs for helpfile generation, key-handler maintenance, and menu auditing as designed.
- fix the /vdm menu dump so it is compatible with the help.html file view and doesn't use hyphens to show indentation.
