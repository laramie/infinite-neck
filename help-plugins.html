Plugins

This page is a standalone help fragment intended to be inserted into help.html later. It uses the same simple structural elements and may borrow the same CSS classes already defined there.

Overview

The Plugins menu adds practice and automation tools that work with the current Song, Section, keys, beats, and visible instruments.

The current plugins are:

  • ArpeggioPlugin: generate note patterns inside a selected fret range and optionally reveal note information as a practice aid.
  • TransposePlugin: move the Song through a programmed interval cycle so one authored Song can be practiced in many keys.

In the command-line menu, plugins live under the plugins runtime branch. Typical menu flow begins with a plugins step such as p plugins.

ArpeggioPlugin

ArpeggioPlugin generates a sequence of highlighted notes from the named notes already present in the current Section. It is designed for practice tools, neck-position drills, key practice, and note-memory exercises.

Typical Use Cases

  • Practice one chord or arpeggio shape in many keys without authoring a separate Song file for each key.
  • Limit practice to a small region of the neck by setting minFret and maxFret.
  • Hide all normal named notes on the neck, then let ArpeggioPlugin reveal only the current notes you want to practice.
  • Use flashcard mode so you guess first, then see the answer on the next beat.
  • Combine ArpeggioPlugin with TransposePlugin so one Song becomes a multi-key practice tool or game.

Core Options

  • m minFret: lowest fret considered by the generated pattern.
  • t maxFret: highest fret considered by the generated pattern.
  • o lowToHigh: control whether the candidate traversal starts from lower strings and lower frets or the reverse logical order.
  • u upOnly: keep the pattern moving upward instead of bouncing back.
  • s style: choose every, alternate, random, or bach.

Note-Name Display Options

  • n show note name: choose how much note text ArpeggioPlugin should reveal.
  • c color notes: when off, revealed note text uses the Emboss look; when on, it uses the AutoColor class the note would have had.
  • f flashcard: delay note-name reveal by one beat so you can guess first and check on the next beat.

Show Note Name Modes

  • off: show only highlights, with no note-name text.
  • one: show only one beat's note-name text at a time.
  • all: show note-name text for all generated beats in the current Section.
  • played: accumulate note-name text beat by beat as the pass continues.

Flashcard Mode

Flashcard mode changes the timing of note-name reveal, not the highlight itself.

  • On beat 1 you see the highlight only.
  • You play and guess the note on your physical instrument.
  • On the next beat, the previous note's information is revealed.
  • On the final beat, the current note is also revealed because there is no later beat to show it.

This creates a simple rhythm for practice:

  • see the highlight
  • guess and play
  • see the answer on the next beat

Practical Practice Flows

Highlight Only

Set n show note name to off. This is the most demanding mode. You see fretboard position only.

Embossed Prompt Notes

Hide normal named notes through the View controls, then set Arpeggio's note-name mode to one, all, or played with c color notes off. The generated prompts stand out from the rest of the neck without using the full AutoColor palette.

AutoColored Prompt Notes

Leave the rest of the neck visually plain or hidden, then set c color notes on. Arpeggio's prompt notes will use the current AutoColor mapping and can stand out strongly inside the selected fret range.

Flashcard Drill

Set f flashcard on and choose a note-name mode. This is useful when you want a short delay between the guess and the reveal.

Actions

  • A Apply: regenerate the current Section immediately using the current settings.
  • C Clear: remove Arpeggio-generated notes from the Song without touching user-authored notes.
  • h help: show a summary of the current Arpeggio settings.

Example Command-Line Flow

One possible command-line rhythm is:

  • p plugins
  • a arpeggio
  • m minFret and t maxFret
  • n show note name
  • c color notes
  • f flashcard
  • A Apply

TransposePlugin

TransposePlugin lets one Song move through an interval cycle instead of requiring many separate authored files for every key.

Core Idea

You provide a list of intervals. The first interval is treated as the starting state. Each trigger advances to the next interval and applies only the difference from the currently applied interval.

Options

  • i intervals: JSON integer array of target transposition intervals.
  • n named notes: transpose named notes when enabled.
  • p played notes: transpose played-note layers when enabled.
  • r recorded notes: transpose recorded-note layers when enabled.

Action

  • a apply: advance to the next configured interval immediately.
  • h help: show a brief summary of current transpose behavior.

Typical Use Cases

  • Take one authored Song such as a chord or scale drill and practice it in all 12 keys.
  • Pair with ArpeggioPlugin so the same authored practice pattern can move across keys automatically.
  • Reduce maintenance of many nearly identical Song files that only differ by key.

Arpeggio And Transpose Together

The two plugins are especially useful together.

  • TransposePlugin changes the key progression over time.
  • ArpeggioPlugin regenerates and displays practice prompts inside the current fret range and display mode.
  • The user can choose whether the neck is fully labeled, mostly hidden, color-coded, or used in flashcard style.

Keyboard And Menu Reminders

Plugin options are exposed through the command-line menu system. The highlighted trigger letter in each menu item is the letter to press, just like the rest of the command-line menus in help.html.

Example trigger styling:

  • A Apply
  • C Clear
  • f flashcard

Regular keyboard shortcuts in the main UI, such as transport or note-entry commands, continue to use the same visual convention as the rest of help.html, for example A or Tab.
