ArpeggioPlugin

/fpa ArpeggioPlugin
Enable When Enabled, Arpeggio highlights NamedNotes in each section while looping
Load enabled Enable automatically when the song is loaded
Bury Save the current plugin settings in the Graveyard, with a name
Instrument The Instrument that the Arpeggio is applied to
Apply Apply the current settings to the selected Instrument, in the Current Section
Clear Clear any notes Applied by Arpeggio in the Current Section
