Plugin Help Topics

ArpeggioPlugin

/fpa ArpeggioPlugin
Enable When Enabled, Arpeggio highlights NamedNotes in each section while looping
Load enabled Enable automatically when the song is loaded
Bury Save the current plugin settings in the Graveyard, with a name
Instrument The Instrument that the Arpeggio is applied to
Apply Apply the current settings to the selected Instrument, in the Current Section
Clear Clear any notes Applied by Arpeggio in the Current Section
positions See: /fpap Limit arpeggios to positions, such as "first position", frets 0-4, or ranges of positions, such as 0-3,4-8, and 8-12.
strings See: /fpas Limit arpeggios to the range between the lower and upper strings chosen.
low to high "Low" is the last string on the neck, the lowest on the web page, the lowest musical note on a Standard-tuning guitar (the Sixth string). The arpeggio goes from the lowest string towards the highest string, and back down again if the style, and "low to high", and the number of beats allows it. The low string can be specified to be a number less than the maximum with the strings option:/fpas.
up only "Up" is the direction of "low to high", but doesn't descend. Instead, if there are enough beats, it starts over at the bottom.
style Several styles of how the algorithm chooses notes for the arpeggio.
show note name Several choices for how to display/reveal the notes of the arpeggio, especially useful when in Flashcard mode.
color notes Whether to color the notes as the arpeggio plays them. Escpecially useful if you have turned off Auto-color so all other notes are Emboss which is black and white.
flashcard Flashcard mode lets you delay seeing the name of the note until the next beat after it is highlighted, so you can practice guessing the note name by seeing its location first.
help Shows plugin help in the ShowMessages area below all the Instruments
