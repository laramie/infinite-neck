Note that the current value in square brackets have been removed, along with the square brackets. The elements have been preserved, but each
element has been transformed into wrapping td elements etc. Note that `sub-menu` has one more `td` for indentation than `menu`. Note that each menu and sub-menu get the menu-path three-column-span row. Paths that are deeper do not cause more indentation with more table columns--there are only menus and sub-menus--all sub-menus get the three-column-span even if they are deeper paths such as /fpfoNr . Note that the row for /fpa has been started simply to show how the next menu or sub-menu would continue the table.
